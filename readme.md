# 🎨 Real-Time Collaborative Drawing Canvas

A multi-user drawing application that allows multiple people to draw simultaneously on the same canvas with real-time synchronization using **WebSockets (Socket.io)** and **HTML5 Canvas**.

---

## 🚀 Features

- **Real-time Drawing**: See others’ drawings instantly as they draw.
- **Brush Tools**: Adjustable color and stroke width.
- **Eraser**: Quickly remove parts of the drawing.
- **Undo/Redo (Global)**: Works across all users.
- **User Indicators**: See who is online and where they are drawing.
- **Conflict Handling**: Efficient synchronization of overlapping strokes.

---

## 🧰 Tech Stack

- **Frontend**: Vanilla JavaScript + HTML5 Canvas + CSS  
- **Backend**: Node.js + Express + Socket.io  
- **Communication**: WebSocket (bi-directional real-time data)
